Privacy Policy

Drylest Shorts Publisher · Effective 20 November 2026

Drylest Shorts Publisher is an internal tool operated by Drylest (Pvt) Ltd (company no. PV 00269952, Matale, Sri Lanka). It creates short educational videos and publishes them to YouTube channels that Drylest owns. It is not offered to the public, and only Drylest's own Google account signs in to it.

What data the tool accesses

Through Google OAuth, the tool requests access to the YouTube account that signs in to it, using the YouTube Data API. It uses that access only to:

  • upload videos to the authorised channel and set their title, description, tags and publishing schedule;
  • read basic details of the authorised channel and of the videos it uploaded, to confirm uploads succeeded;
  • delete videos it uploaded by mistake.

The tool does not access, collect or store data about YouTube viewers, other channels or any other Google services.

How data is stored and protected

The OAuth access token for Drylest's account is stored as an encrypted secret in a private repository and on Drylest's own computers. It is used only to run the tool, and is never sold, shared or used for advertising.

Third-party services

To make videos, the tool sends the video topic and script text (never Google account data) to: Google Gemini (script writing and fact-checking), ElevenLabs (voice-over), and fetches images from Wikimedia Commons, Openverse, Imgflip and GIPHY.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Drylest's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions. Revoking access stops the tool from uploading; Drylest then deletes the stored token.
